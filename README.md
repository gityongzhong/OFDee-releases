# OFDee

> OFD / PDF 桌面阅读器 —— 自研 OFD 渲染内核，便携版单文件，双击即用。

国内电子发票、红头文件大量使用 OFD 格式，多数阅读器打开后字体错位、行距变形。OFDee 自研渲染内核，**内嵌字体与字距版式原样呈现**，红头文件的版式不再走样。全程本机渲染，不联网。

## 下载

前往 [Releases](../../releases/latest) 下载最新的 `OFDee-vX.Y.Z-portable.zip`，解压即可运行。

> 本仓库只存放安装包，不包含源代码。

## 特点

- **OFD 原生渲染**：不用转 PDF 再显示，直接解析 OFD 版式，内嵌字体按原文档嵌入方式还原
- **OFD / PDF 双格式**：同一个窗口打开两类文件，切换无感
- **便携单文件**：不写注册表、不装运行库，放 U 盘里直接带走
- **轻量**：冷启动快，低配机器也不卡

## 系统要求

- Windows 10 / 11（64 位）
- 免安装，无需额外运行库
